# simple calculator
A simple calculator made using python.
___
## Features
- Addition
- Subtraction
- Multiplication
- Division
- Checks if the user enters an invalid number
- Checks if the users enters an invalid operator
- Prevents division by zero
___
## how to use
1. Run the 'calculator.py' file.
2. Enter the first number.
3.Enter the second number.
4. Choose an operator.
5. The calculator will show the result.
